1. 任何页面都要以内容、语义为中心，不要添加没有语义的视觉元素
2. 如果不是内容、语义所必须，不要在内容区设置卡片。如果要分隔不同的区域，请使用灰色的细线分隔
3. 不要使用渐变和阴影。对于需要用户确认或专注修改设置的 popup 等一定需要与其他内容分层的内容，请使用白色或黑色毛玻璃盖住背景
4. 对于强调内容的大幅图片、代码、视频和表格，直接使用矩形，对于按钮等操作性的小组件，使用圆角矩形
5. 控件不应该为了“设计感”而过度留白，但也不应该过于紧凑
6. 按钮除了有少数例如紧急的红底等特殊底色的按钮，分为主题色底按钮、灰底按钮、灰色边框按钮和透明底色按钮。主题色底按钮被用于被醒目强调的操作，灰色边框按钮和透明底色按钮更侧重于供用户有需要时点击，不被强调的杂项操作按钮。
7. 使用白色和灰色作为主要颜色，使用 Umamichi aqua（“水色”）（@umamichi-ui/common-css 下的 theme-*）色作为突出和品牌识别用的主题色，除此以外，你可以在语义表达必要时，使用微量其他颜色
