# Umamichi UI Conventions

> [!WARNING]
> **已弃用 / Deprecated.** 本仓库记录的 UI 约定属于已停止的自制组件路线，仅作历史参考，不再主动维护（仓库保持公开可读，未归档）。
>
> 自制组件路线在视觉设计、可访问性、代码维护等方面遇到了不小的困难，我们计划改为对现有 UI 框架进行定制，作为专用 UI 视觉方案。
>
> The UI conventions recorded here belong to the discontinued custom-component route and are kept for historical reference only. The custom-component route ran into considerable difficulties in visual design, accessibility, and code maintenance; we are moving to customizing an existing UI framework as our dedicated UI visual layer.

各个项目公用的 UI conventions 文档整理仓库。

这个仓库用于沉淀跨项目共享的界面与交互约定，作为 Umamichi UI 风格的文档来源，而不是某个单一项目的实现细节备份。
